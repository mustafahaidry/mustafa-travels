MUSTAFA TRAVELS HOME V4 - SAFE INSTALL

This version is deliberately self-contained so the homepage design cannot break because a new CSS file was not uploaded.

UPLOAD ONLY:
1) index.php -> website root (replace current index.php)
2) assets/images/owner-original.jpg -> assets/images/

DO NOT REPLACE:
- style.css
- partials.php
- config.php
- admin.php
- database/API files

Before upload, keep a backup of the current working index.php.
After upload, hard refresh browser: Ctrl+F5.
