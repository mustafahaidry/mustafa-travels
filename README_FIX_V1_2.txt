Mustafa Travels Website V1.2 Localhost Fix

Fixes:
- PDO SQLite 'unable to open database file' on Windows/XAMPP.
- Creates data/uploads folders automatically.
- If /data is not writable, uses PHP/XAMPP writable temp storage automatically.

For XAMPP:
1. Extract this folder.
2. Copy MustafaTravels_Website_V1_2 to C:\xampp\htdocs\
3. Open:
   http://localhost:8081/MustafaTravels_Website_V1_2/
4. Admin:
   http://localhost:8081/MustafaTravels_Website_V1_2/admin.php

Default admin:
admin
